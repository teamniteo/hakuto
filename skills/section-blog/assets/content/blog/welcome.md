## A section heading

Body text goes here. Use `##` for sections — the post title is already the page's only `<h1>`, and a `#` heading in the body is demoted to `##` automatically.

To add images, put them in `src/content/blog/_images/` and reference them relatively:

```markdown
![Describe what the image shows](./_images/example.jpg)
```

The same relative path works for `featuredImage` in the frontmatter.
