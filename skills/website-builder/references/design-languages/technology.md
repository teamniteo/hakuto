# Technology Design Language

Principles reference — palettes and fonts are generated fresh per project (brand-designer color-wheel rules, fonts skill). Nothing here is a menu to copy.

## Aliases
Tech, Terminal, Developer, Code, Hacker, Cyber, Digital

## Attitude

Built for people who live in editors and terminals. Credibility comes from precision, speed, and restraint — the site should feel like a well-made tool, not a brochure. Functional over decorative; structure is allowed to show.

## Principles

- Monospace as an accent voice — labels, nav, code, badges — never body text
- Real code is the imagery: syntax-highlighted blocks, actual CLI examples, real product UI; never div-built fakes
- Interactions snappy (100–200ms); slow easing reads un-technical
- Visible structure decorates: borders, grids, alignment — not glows and gradients
- Sharp edges (radius 0–4px); technical symbols (`→`, `$`, `✓`) welcome in moderation
- High contrast throughout; dark-first is typical but a stark light variant is equally valid

## Dial Presets

VARIANCE 5–7 · MOTION 3–5 · DENSITY 4–6
Push VARIANCE up for devtool startups wanting personality; pull toward 5 and DENSITY up for infra/enterprise where docs-like clarity wins.

## Palette Strategy

Dark-first (near-black with a blue or warm undertone — never pure #000) or stark light. Triadic scheme; one electric accent owns CTAs and interactive states, a second desaturated tone supports. Vary the accent hue per project — terminal green/cyan is the cliché default; amber, magenta, cobalt, or orange read equally "technical."

## Typography Strategy

Geometric or grotesque sans display + monospace accent, or monospace display + humanist sans body for a bolder statement. Hard weight contrast (400 body / 700–800 display). Monospace body text is banned — readability first.

## Watch Out

- Not everything neon green (Matrix cliché) — and glow effects read amateur past one element
- Fake terminal windows with traffic-light chrome are the tell; show real code instead
- Don't confuse with Dark: Technology = for developers specifically (monospace, terminal heritage, snappy); Dark = premium dark-mode for any audience (smooth, elegant, no code refs)
- Tech aesthetic for a non-technical audience alienates — check who's actually buying
