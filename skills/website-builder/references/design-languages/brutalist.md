# Brutalist Design Language

Principles reference — palettes and fonts are generated fresh per project (brand-designer color-wheel rules, fonts skill). Nothing here is a menu to copy.

## Aliases
Brutal, Raw, Brutalism, Anti-design, Stark, Utilitarian, Raw web

## Attitude

Raw, honest, intentionally stark — brutalist architecture translated to HTML. Rejects conventional polish for functional honesty; the structure IS the decoration. Critically: this is deliberate anti-polish with strong art direction, not amateur or broken design. Confirm the user actually wants this before committing.

## Principles

- Exposed structure: visible borders (2–4px, solid), grid lines as design elements, raw HTML elements (`<hr>`, tables) worn proudly
- Stark contrast and bold type: ALL CAPS headlines, heavy weights, huge scale swings
- Interactions instant — no smooth transitions; hover = invert, bold, or underline, immediately
- Zero gradients, shadows, glows, or rounded corners
- Text symbols over icon libraries (`→`, `×`, `☰`); ASCII dividers acceptable
- Rough edges intentional but usability intact — brutalism is never an excuse for broken

## Dial Presets

VARIANCE 7–10 · MOTION 1–2 · DENSITY 5–7
The one language where MOTION stays at the floor by definition. VARIANCE 9–10 (overlaps, rotation, collage) for art/experimental; 7 with a raw visible grid for editorial.

## Palette Strategy

Monochrome (black on white or inverse) or monochrome plus exactly one violent accent — browser-blue links, warning red, acid yellow. Vary which accent per project. No mid-tones, no subtle neutrals: every color at full commitment. A newsprint-cream background variant works for editorial brutalism.

## Typography Strategy

System font stack used boldly, or monospace everything (typewriter register). Weight and scale do all the work: 700–900 display at extreme sizes against plain 400 body. Underlined links, always. No web-font preciousness — the rawness is the statement.

## Watch Out

- The line between intentional and broken is art direction — if it could be mistaken for unstyled, push the type bolder
- Wrong for e-commerce, corporate, healthcare, finance — audiences who read rawness as untrustworthy
- Accessibility survives the aesthetic: contrast, focus states (thick borders), semantic HTML, keyboard nav
- Accidentally adding polish (a soft shadow here, a radius there) dilutes it into nothing
